04 Misreadings

Postmortems.

Every bug I've spent more than two hours on has taught me something I didn't know I didn't know. These are the ones that rewired my mental model.

PM-01
GOROOT path bug in Termux installer
The installer assumed Go was in /usr/local/go. On Termux, it's /data/data/com.termux/files/usr/lib/go. I spent an hour blaming the script before I checked the actual path. Now I probe $GOROOT before any build step.
PM-02
Nested tools/tools/ folder
ReconOS's plugin discovery walked ./tools and found a subfolder also named tools from a git submodule. It double‑registered every tool. Fix: canonicalize paths and skip any folder whose resolved path matches an already‑loaded plugin's parent.
PM-03
Async stdout/stderr deadlock
My FastAPI orchestrator spawned subprocesses and read stdout and stderr sequentially. When a tool wrote more than the pipe buffer to stderr, it blocked waiting for the reader — which was still waiting for stdout. Fixed by reading both streams concurrently with asyncio.gather().
PM-04
Believing the error message
The installer said "permission denied" on a file that was world‑readable. The actual problem was that the parent directory was on a mounted filesystem with noexec. The error was a lie. Now I check mount options before I trust any permission message.
05 Disclosure Practice

How I handle findings.

Verify before you write. I don't report something I can't reproduce cleanly. Every report I send to CERT‑In includes a clear reproduction, the affected system, and no speculation about impact I can't prove.

I document conservatively — I state what I observed, not what I suspect. I wait on organizational timelines. Disclosure is a conversation, not a deadline. I've reported to government, education, banking, and healthcare sectors. I never name targets.

— This is the ethic that separates research from noise.
